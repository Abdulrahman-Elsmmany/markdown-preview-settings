Markdown Preview Field Notes

A visual fixture for comparing fifteen distinct dark themes. It includes long-form text, linked sections, inline const theme = "active", highlighted notes, and a keyboard shortcut such as Ctrl + Shift + V.

Reading Surface

Good preview styling should make a dense document easier to scan without turning every element into decoration. The themes in this repository intentionally vary layout density, typography treatment, borders, color systems, and code presentation.

Note: The same Markdown structure should feel different without losing clarity.

Review Checklist

  • Check heading hierarchy and paragraph contrast.
  • Compare inline code against fenced code blocks.
  • Inspect lists, quotes, tables, and expandable details.
  • Theme tokens loaded
  • Preview reloaded after switching

Code Sample

const themes = ["vera", "linen", "terminal"];

function activate(theme) {
  return themes.includes(theme) ? theme : "vera";
}
